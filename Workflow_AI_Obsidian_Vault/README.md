# Workflow AI Obsidian Vault

Open this folder as a vault in Obsidian. Start with `00 - Start Here.md`.

The vault contains product requirements, UX/design requirements, functional requirements, architecture, data model, API contracts, AI/ML boundaries, security, a 7-day MVP sprint, an 8-week academic roadmap, acceptance criteria, and agent instructions for Claude and Antigravity.

Use the Markdown files as the canonical project specification. Update `14 - Decisions and Open Questions.md` as the team makes decisions.
