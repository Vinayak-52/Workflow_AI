# Purpose

This roadmap preserves the submitted eight-week plan and maps the
expanded product direction into it. It is a planning aid; confirm any
changes with the mentor/team.

## Week 1 --- Requirements and foundation

-   Member 1: finalize ML requirements, priority factors and AI
    workflow.
-   Member 2: Git repository, Node/Express project, database design.
-   Member 3: React project, dashboard wireframe, component plan.
-   Member 4: research-to-feature mapping, test plan and acceptance
    criteria.
-   Extension: agree Gmail/Calendar read-only integration and
    notes-first focus UX.

## Week 2 --- Data and core CRUD

-   Member 1: synthetic task dataset and baseline priority rules.
-   Member 2: task, note, user and deadline APIs.
-   Member 3: login, dashboard, task-create screens.
-   Member 4: prioritization metrics and sample-data validation.
-   Extension: implement note editor, task CRUD and initial design
    system.

## Week 3 --- Initial ML and integration

-   Member 1: train/evaluate initial Random Forest task-prioritization
    model.
-   Member 2: Firebase/Firestore and authentication.
-   Member 3: integrate task UI with APIs; list/edit/delete interfaces.
-   Member 4: Postman CRUD tests and defect documentation.
-   Extension: implement Google OAuth and Gmail read-only proof of
    concept.

## Week 4 --- Smart reminders and calendar

-   Member 1: reminder logic using urgency, deadlines, workload and
    available time.
-   Member 2: reminder service and notification scheduling endpoints.
-   Member 3: calendar, priority labels, filters and reminder settings
    UI.
-   Member 4: test priority/reminder cases, including missed/overdue
    tasks.
-   Extension: Calendar read-only integration, timezone-aware live clock
    and free-time calculation.

## Week 5 --- Summarization and documents

-   Member 1: integrate/evaluate pre-trained summarization model.
-   Member 2: document-upload API and Firebase Storage.
-   Member 3: upload, notes and summary-result screens.
-   Member 4: document test set and summary quality evaluation.
-   Extension: contextual AI panel and email/note summarization.

## Week 6 --- Feedback and recommendations

-   Member 1: improve priority model using completion-history feedback;
    define continuous-learning workflow.
-   Member 2: activity logging, model-input endpoint, validation and
    error handling.
-   Member 3: recommendation panel, loading/error states and responsive
    UI.
-   Member 4: integration testing across frontend, APIs, database and AI
    services.
-   Extension: cross-module daily planning with provenance and human
    review.

## Week 7 --- Documentation and deployment

-   Member 1: document model, fields, limitations and future RL
    enhancement.
-   Member 2: cloud deployment, API documentation and backup rules.
-   Member 3: polish UI, accessibility and live demo screens.
-   Member 4: user testing, security/privacy checks and regression
    testing.
-   Extension: OAuth scope review, token lifecycle, privacy UX and
    read-only boundary audit.

## Week 8 --- Final demonstration

-   Member 1: present AI methodology and final model results.
-   Member 2: deploy prototype and support live demo.
-   Member 3: demonstrate frontend workflow and dashboard.
-   Member 4: compile test report, references, risks and final QA.
-   Extension: demonstrate an end-to-end workflow from email to
    note/task to calendar-aware plan.
