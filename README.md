# Workflow AI

A unified productivity workspace that helps users think, capture, organize, understand, and plan without constantly switching applications.

## Project Structure

```
Workflow_AI/
├── client/       # Frontend application (React + Vite + TypeScript + Tailwind)
├── server/       # Backend API server (Node / Express)
├── ml/           # Machine learning services & models (Python / scikit-learn)
├── firebase/     # Firebase configurations, rules, and functions
└── README.md     # Project overview
```
